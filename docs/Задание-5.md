Задание 5. Создание Dockerfile
В этом задании вы реализуете простое приложение temperature-api, которое будет имитировать работу удалённого датчика и при запросе /temperature?location= отдавать рандомное значение температуры.
Используйте любой удобный для вас язык программирования.
Что нужно сделать
Упакуйте приложение в Docker и добавить в docker-compose. Порт по умолчанию должен быть 8081.
Для smart_home приложения требуется база данных. Добавьте в docker-compose файл настройки для запуска postgres с указанием скрипта инициализации ./smart_home/init.sql.
Для проверки можно использовать Postman коллекцию smarthome-api.postman_collection.json и вызвать:
Create Sensor
Get All Sensors
При каждом вызове должно отображаться разное значение температуры.
Используйте шаблон для заливки в GitHub.
